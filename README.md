# YourFocus

This is the sourcecode for the unbuilded version of [YourFocus](https://store.steampowered.com/app/4037900/YourFocus/).

![header](https://github.com/user-attachments/assets/4e081f34-393b-4aba-959f-f0aac4781b5d)


## How to get YourFocus?
Download YourFocus as a setup file for supported platforms, build it your own or download it on steam directly.

### Plattforms
#### Windows Info
The Windows version of YourFocus is provided on steam for free or can be build by your own and used privatly.
Steam will receive the newest updates directly.

#### MacOS Info
Due to some regulations on steam we cannot provide official macos support on steam.
We can provide you an unsupported version for apple silicon macs using arm64 *(dmg with APFS - supports Mac OSX 10.12+)*. Download the .dmg.
This is why we only can provide it here without signings. It is build using electron too.

#### Linux Info
Currently no Linux build made.

### Build
#### How to build?
Install npm
```
npm install
```
Run Dev
```
npm run dev
```

Build project
```
npm run dist
```
